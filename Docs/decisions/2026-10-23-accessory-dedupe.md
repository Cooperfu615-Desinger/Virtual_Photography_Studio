# 決策：隨機配件不重複衣物已含物件（2026-10-23）

- 決定者：Cooper（照建議，三項待辦中先做這項）。
- 決定：隨機抽到的頭部配件、耳環、頸部、腰部、襪類、鞋款，若名稱已出現在已放入的衣物或配件文字中，從其餘候選重抽；使用者鎖定的配件不動。
- 取捨：
  - 採「抽後檢查、重複才重抽」而不是事先過濾候選：事先過濾會改變所有候選的索引，讓所有隨機結果位移；重抽只在重複時多抽一次亂數，其他結果逐字不變。
  - 以英文物件名稱比對，不做視覺判斷。
  - 不處理顏色／圖案描述在多件衣物重複寫的情況（機制不同，另案）。
- 放棄的方案：事先從候選池排除（會改變全部隨機結果）；在輸出階段用字串刪除重複（會刪掉使用者鎖定的內容、且已選擇快照與輸出不一致）。
- 規格見 [accessory-dedupe-v1](../specs/accessory-dedupe-v1.md)。
