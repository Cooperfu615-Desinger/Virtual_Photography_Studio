# C3 說明與隱藏狀態決策

依 Cooper 授權，採現行說明護欄＋六筆隱藏標記。早期報告的 101 筆公開缺說明與六筆死選項不能直接當成現行 UI 問題：自由組合七欄位已退役，新的 54 筆指定動作均有說明。

六筆稱為「全基底隱藏的相容選項」，只補 uiHidden；保留明確舊鎖值、現行 PAGE1 清值政策、英文、ID、metadata 其他欄位及所有歷史基準。五個既有缺說明項因加隱藏標記退出舊統計，並非補寫完成。

現行手勢／頭部／視線沒有獨立說明是既有介面決策；新增提示、自由支撐能力或移除相容資料須另案。P5b 等暫緩項目不併入。

初次完整測試顯示舊歷史精確來源不符，採 C3 專用前後 SHA 反轉並在 C4 隔離回放入口銜接；不改歷史預期。本批產品差異限定六個布林標記。
