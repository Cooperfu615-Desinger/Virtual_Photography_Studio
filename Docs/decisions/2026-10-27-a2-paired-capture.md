# A2 上下配色抓拍快照相容決策

2026-10-27；基準 `58516b20c6631b1a61faa48ee22abfb05ea29384`。

- 成因是合法巢狀色塊沒有 ID，舊驗證卻只接受 ID 物件。42 組方案的一般分件也受影響，前批只記錄舊連身案例的範圍不足；此說明補充當前認識，不改寫舊報告。
- 方案 ID 與內部色塊責任分開。保留原配色物件，不補色塊 ID、不轉成一般色票，不改 renderer 或共用選值。
- 無 ID 分支按已知配色欄位、同人物／同區域來源及 zh／en／hex 完整一致驗證；不能以任意物件放行取代驗證。
- 休眠一般選值可能仍是 random，匯入人物內部 selection 才是當時解析的方案。兩者都要保存；重抽只改抓拍組合，重新匯入才換人物快照。
- 固定 Git 普通輸出逐字對照；合法新來源以隔離的原始快照 oracle 驗證。oracle 略過舊 ID-only gate 只限可信生成案例，產品沒有略過驗證的開關。
- 舊連身還原仍清掉上下配色；套裝／分件互斥、舊文字辨識與胸上投影另批。雙人與角色卡不因此變成可匯入的普通單人來源。
- 前批測試更新當前抓拍預期，歷史安全測試先在記憶體取回固定前版，再驗證其原 inverse。所有舊 patch manifest、報告與 A～E 基準保持；本批另有精確 inverse 及完整鏈回放。
- 只授權本機實作與驗收；不 stage／commit／push，也不進入其他項目或 P5b。
