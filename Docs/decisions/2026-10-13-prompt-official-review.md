# 2026-10-13 七種 Prompt 輸出 × 官方規範檢視：範圍與方法

- 產出：[Docs/reports/prompt-official-review-2026-10-13/README.md](../reports/prompt-official-review-2026-10-13/README.md)
- 起因：Cooper 說明了各輸出依據的官方規範（GPT Image 2.5、Z-Image Turbo＋實測、Midjourney V8.2、Nano Banana 2.1），要求從官方角度重新檢視。

## 採用的決策

| 決策 | 理由 | 放棄的方案 |
| --- | --- | --- |
| 依模型家族分 4 位研究員並行，只用官方來源 | 需要上網查證；版本與來源必須可追溯 | 單一 agent 一次查完：時間長，也容易混淆各家規範 |
| 先產生七種輸出的實際樣本，再拿樣本對照規範 | 用真實輸出檢視，不靠推測；同一份樣本供 4 位研究員共用 | 只讀 renderer 程式碼：看不出串接後的實際瑕疵 |
| Cooper 的實測結論優先於官方的一般建議 | 例如 Z-Image 格式是實測決定的；這類差異只標成取捨，不列為錯誤 | 一律以官方為準：會推翻已驗證有效的格式 |
| 只檢視、不修改 | 所有修正都會改變公開 Prompt，需要逐項核准並實測 | 順手修正低風險的格式問題：違反「分析不實作」原則 |
| 官方文件原文副本不收進 repo | 屬版權內容；報告只保留轉述與 15 字內的短引 | 收錄原文方便查閱：有版權疑慮 |

## 主對話自行查證的結論

- Z-Image 研究員回報 `She wears,` 在 200 筆 audit 中出現 0 次。主對話以 `tools/tops_probe.mjs` 重現了這個 bug：它只在特定組合下觸發。兩種說法都成立，報告已註明觸發條件。
- 主 MJ 樣本的參數尾綴確實沒有 `--ar`；Nano 與 GPT 的標點、大小寫瑕疵都已在樣本中確認。
- Z-Image 在 Magnific 上是否也在 512 token 截斷：官方沒有說明（not_stated），報告列為必須實測的項目。
