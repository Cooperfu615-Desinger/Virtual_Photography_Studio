## 實作時自行決定的技術細節（可逆，影響僅限本專案）

| 決定 | 理由 |
| --- | --- |
| 單人寫法 `adult Japanese woman`（插在 `adult` 與 `woman` 之間） | 句子其餘部分不變，改動最小，反函數也最單純 |
| 只在渲染時套用，不寫入選擇快照或 `structured.Character` | 選擇快照與 Saved Cards 是相容面；寫入合成五官會讓舊卡片與新卡片的資料不一致，也會讓「全無」在 UI 上看起來被改掉 |
| 雙人一人全無時用 `Japanese facial features` 並放在該位五官原本的位置 | 沿用各輸出既有的角色描述位置，不新增句型 |
| 混血立體臉、角色卡、特殊主體、自訂身份、附圖參考預覽不套用 | 混血已有自己的身份；其餘有各自的身份契約 |
| 凍結基準用精確反函數比對，不重算雜湊 | 依專案慣例，能證明唯一變化就是本次插入 |

## 放棄的方案

| 方案 | 放棄原因 |
| --- | --- |
| 在 buildCharacter 注入合成的「日系五官」項目 | 會被選擇快照與結構資料保存，改變相容面 |
