# 決策：新增道具欄（2026-10-22）

- 決定者：Cooper。新增獨立的「道具」欄，放回舊道具 10 個、單手拿著眼鏡，另加「拿著打開的書」。
- 與指定動作、手勢先完全並存，不做篩選，實測後再收。隨機只避開背面機位的碰臉／遮臉道具。
- 取捨：
  - 新鎖定欄位 `propId`，不重用 `posePropId`，避免動到舊自由組合的資料與基準。
  - 面板的「隨機」不強加道具（重設為全無），避免每個隨機結果都帶道具；與手勢不同。這是我的決定，若要比照手勢請告訴我。
  - 眼鏡道具沿用手勢的穿搭規則；鏡子自拍時道具欄鎖住。
- 放棄的方案：把道具併進手勢欄（Cooper 選獨立欄）。
- 規格見 [pose-props-v1](../specs/pose-props-v1.md)。
