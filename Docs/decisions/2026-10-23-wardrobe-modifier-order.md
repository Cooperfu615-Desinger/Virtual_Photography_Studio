# 決策：服裝描述改為衣物名稱在前（2026-10-23）

- 決定者：Cooper（照結構檢視建議，先處理第 1 項，並併入外套雙肩露出寫法）。
- 決定：上衣與下身的版型、褲腰、穿法移到衣物名稱之後；`pants waist` 改成 `waist`；雙肩露出輸出句拿掉 `fully uncovered`。
- 取捨：

  - 凍結基準用測試專用開關維持舊順序，不重錄基準（既有規格禁止用新版覆蓋）。
