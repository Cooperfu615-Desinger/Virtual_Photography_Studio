## 診斷與結案界線

修改前under22／over70／within660／unclassified106；修改後under22／over70／within685／unclassified81。只有25筆狀態與range改變，計詞、來源指紋及其他列逐字相同。within不是無冗詞證明，under／over不能自動修正。

本輪規範與已授權內容批次已處理：初始診斷政策、五腰鍊、20套裝尾句、場景／光學及本批成像分類。完整剩餘診斷清單見 `scripts/lib/c2ClosureInventory.json`（ID、來源SHA、狀態、理由與依據）。173筆包括：

- 38筆已有例外：35筆over、3筆未分類穿法，保留原指紋及專屬責任。
- 7筆under／over已有本輪內容批次審閱：5筆套裝、2筆腰鍊，可追溯各批review，不重複新增例外。
- 78筆其他未分類修飾項，加上前述3筆穿法共81筆：保留未分類，不套完整衣物下限。
- 50筆diagnostic-followup：28筆over、22筆under，只有字數提示，尚無本輪逐筆語意審閱依據；本批登記並保持原文，不能以「保留」冒稱審閱通過。

因此本批完成不等於全目錄C2內容已全面結案。後續可另批審閱50筆候選，或由使用者決定列為非阻斷待辦後轉C5；本批不默認跳過或自動修改。過往「20套裝尾句」不是全部套裝字數審閱，已審閱的20筆也不是全部都超長。

## 驗收與歷史

- 固定Git基準比對：只有一條policy rule新增，38例外與既有規則不變。
- before／after診斷精確比較：只25筆range及status、兩項summary計數有差；來源與產生物位元組保持。
- Python完整測試與CLI唯讀性、173筆清單完整性／指紋、過往Python測試原函式內容保持。
- 歷史Python斷言在隔離副本執行；歷史25筆unclassified仍成立。新JS逆向層只反轉本批policy及三個必要銜接檔，拒絕checkout與連結；識別到本批狀態時拒絕未知混合來源，更早未命中本批版本交既有下層工具處理，原封存與patches不改。
- JS既有回放測試與前端全套驗證新銜接；本批不變產品資料，驗證來源位元組不變即可沿用已交付的更早完整歷史鏈，不重錄、不宣稱此次重跑全部舊鏈。
- 唯讀sync/schema/歷史ID、文件連結與diff-check。無產品或UI變更，不要求重新build／瀏覽器／生圖；前批原生下拉與未生圖限制仍保留。

其他C類、PAGE2舊匯入、J12、P5b不併入。實際結果見[驗收報告](../reports/c2-rendering-classification-2026-10-30/README.md)。
