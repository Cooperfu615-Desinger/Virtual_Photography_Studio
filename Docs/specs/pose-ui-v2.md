# B 神情姿態介面 v2：指定動作選擇器改版

- 日期：2026-10-21；狀態：**第一部分已實作**（介面重構，Prompt 不變）；第二部分（頭部）§5 待做。
- 決定者：Cooper（2026-10-21 逐項確認）。

## 1. 主介面

姿勢區由上而下：
1. **全無、隨機、任意**：三張並排的卡片（名稱＋說明，無示意圖）；手機改一欄。全無的說明為「不寫任何姿勢。」，隨機與任意沿用原說明。
2. **六顆分類按鈕**：站姿、蹲姿、上身互動、坐姿、跪姿、躺姿，各顯示該類動作數；選了某類的動作時該按鈕呈選取。點按鈕開彈窗。沒有「全部」。
3. **已選動作摘要卡**（只在選了指定動作時出現）：示意圖格、名稱、說明、「更換」按鈕（開啟該動作所屬分類的彈窗）。選全無、隨機、任意時沒有摘要卡，改為高亮對應的卡。
4. **手勢、表情、視線**：永遠顯示，依 §3 鎖定。

固定場景人物位置或專用特殊角色接管時，整組選擇器停用，原因文字保留。

## 2. 彈窗

- 只列出被點的那一類動作，標題「{分類} · N 組」；沒有分類分頁。
- 卡片左圖右文：圖片格固定 2:3（桌機 72×108、手機 56×84）。有舊示意圖表的動作裁切置中顯示；沒有示意圖的動作顯示中性空白框，之後補圖時版面不會跳動。桌機兩欄，手機一欄。
- 未驗收（pending）動作維持「未驗收」小標。選取後關閉彈窗。
- **示意圖必須是自製的人形示意圖**，不能使用 `Docs/站姿/` 等參考照片（有第三方浮水印，不能放進公開網站）。後續每個動作一張，以動作 ID 命名，只載入目前顯示的分類。尚未實作圖片載入，只預留位置。

## 3. 鎖定規則（Cooper 同意）

| 欄位 | 動作選全無 | 動作選隨機 | 動作選任意 | 選了指定動作 |
| --- | --- | --- | --- | --- |
| 手勢 | 鎖住，顯示「需先選擇動作」 | 只能選全無／隨機 | 鎖住，顯示「由「任意」決定」 | 動作的手空著才開放；手部已固定的動作鎖住，顯示「由動作決定」 |
| 表情 | 開放 | 開放 | 開放 | 開放；動作自己決定表情時鎖住 |
| 視線 | 開放 | 開放 | 開放 | 開放；動作自己決定頭部時鎖住 |

- 鎖住的原因直接顯示在欄位值裡，不再用備注文字。手勢、表情、視線相關備注與原本的「指定動作」大段說明已移除；躺姿表面與仰躺的場景提示、相機衝突提示、固定場景接管提示保留。
- **換動作時不適用的手勢清回全無**（`lockTransitions.js`）：同清單仍適用的保留；跨清單（站→蹲）、手部固定、任意、全無、隨機（只留隨機）都會清除。
- 表情與視線在沒選動作時維持開放：只要表情的人像，以及臉部特寫、頭肩這類不寫姿勢的景別，仍需要它們。

## 4. 實作紀錄

- `SpecifiedActionPicker.jsx`、`specifiedActionPicker.css` 重寫：移除觸發按鈕與分頁、動作編號；新增三張選單卡、分類按鈕、摘要卡、圖片格。
- `Page1Workspace.jsx`：手勢永遠顯示（鎖住時單一選項顯示原因）；移除手勢與視線的 helpText 與整段動作說明備注。
- 驗證：Prompt 輸出（代表性、預設隨機、動作×景別、全部隨機共 1642 筆）與 main 逐字相同；strict audit 相同；`npm test` 1755/1755（連跑 2 次）、Prompt Quality 745/745、lint、build、sync、Python、公開資產、diff-check；瀏覽器 1440×1000／390×900。
- 瀏覽器發現並修正：隨機、任意卡被當成動作而出現摘要卡；標題列規則被誤刪；手機版圖片格尺寸被後面的規則蓋掉；全無卡文字置中。

## 5. 第二部分：頭部（待做，Cooper 同意）

「頭部」與「視線」拆成兩組。頭部復活 5 個與動作、方向、支撐面無關的選項：頭部微微側傾、下巴微抬、下巴微收、頭靠近肩膀、頭部微微後仰（沿用 `poseHeadId` 與既有英文）；視線維持 4 個。兩者並存時合併成一句；視線選「低頭」時，下巴微抬與頭部後仰停用；預設全無；全部隨機時頭部設為隨機。會改引擎組句與 Prompt，另做一個 PR。
