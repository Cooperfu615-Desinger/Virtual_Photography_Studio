## 行為與相容性

- 貼合效果屬於新款服裝來源；不綁定體態、不新增全域身體修飾，不修改 Body Type 或 Character Card 身份。
- 依既有單人／雙人 A/B、配色、圖案、造型優先權及隨機流程解析；不增加選擇鍵或 storage schema。
- 三個 renderer 使用同一份有效服裝投影。GPT 完整保留來源；Z 依原來源精簡；AI 對這四款保留投影後可見的剪裁／貼合片段、已選圖案及有效穿法。
- 新上身不輸出一般上衣與低腰下身的衣長銜接，也不套用衣襬遮住部分下身。
- 胸上輸出保留新上身與其貼合，省略下身及繫繩壓痕。五官裁切依原服裝排除規則；全身角色照保留完整服裝並維持原比例。
- 雙人部分景別的 AI 保留新款所在人物已投影的服裝來源，以免壓縮丟掉杯緣／繫繩效果；另一人物維持原路徑。
- 沿用既有版型／穿法控制，不因新款自動替換使用者選擇。
- 新下身不擴充既有自動吊襪帶白名單；本次授權為四款服裝與貼合效果，無新增自動加層行為。
- Saved Cards、標準 Prompt 匯入及回填使用原選擇格式；舊卡原文不批次修改。
