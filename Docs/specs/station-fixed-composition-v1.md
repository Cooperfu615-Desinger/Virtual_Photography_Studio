## 控制與相容性

- 新選項追加在既有固定構圖清單後方，沿用 `fixedCompositionSetId` 和還原流程。原本一般場景、既有固定構圖和 IDs 不變。
- 只有這三組以 `allowsLensVariation: true` 開放焦段。其他固定構圖仍將焦段設為全無且停用。
- 既有 `orbitId` 在這三組的 UI 名稱為「人物面向（場景取景方向固定）」。八種選項只敘述人物朝向，不生成繞人物拍攝的相機方位語句。離開這三組恢復原本名稱／規則。
- 保留既有固定構圖 9:16、景別與光學效果接管規則。俯仰角度仍可選；自拍等模式仍遵循原本構圖優先權。
- 焦段可沿同一月台方向調整拍攝距離、裁掉周邊元素，不要求廣角與長焦同時容納所有物件。所選焦段的視野／透視來源保留，不固定改成 28mm。
- 本批不新增人物位置或背景狀態子選項；沿用既有捕捉模式與表現狀態。
- 不暗中覆寫使用者快門。倫敦列車來源描述為靜止停靠，不指定行駛或拖影；左右配置、透視、文字也不保證像素級控制。
