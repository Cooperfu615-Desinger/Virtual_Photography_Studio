# 道具欄 v1

- 狀態：**已實作**（2026-10-22）。Cooper 2026-10-22：新增「道具」欄，放回舊道具 10 個＋單手拿著眼鏡，另加「拿著打開的書」，共 12 個；與指定動作、手勢先並存、不做任何篩選。

## 1. 規則

| 項目 | 規則 |
| --- | --- |
| 位置 | B 單人設置，手勢旁；鎖定欄位 `propId`（不動舊 `posePropId`） |
| 選項 | 全無、隨機、12 個道具（英文沿用舊道具；書與眼鏡見下）；「手持手機對鏡自拍」仍是 E 區拍攝方式「鏡子自拍」 |
| 適用 | 所有動作皆可選（含手固定的動作、蹲姿、躺姿、全無）；不篩選衝突，由實測決定之後怎麼收 |
| 寫法 | 有動作：加在動作句的上身子句之後（同手勢），四個主輸出與胸上都寫入；沒有動作：走舊自由組合的單獨道具句 |
| 隨機 | 12 個都抽得到；背面機位不抽會碰臉或遮臉的 5 個（塗口紅、相機、波板糖、含棒棒糖、眼鏡）；穿搭沒有眼鏡時不抽眼鏡 |
| 眼鏡 | 穿搭眼鏡明確選「全無」時停用並標「（需要眼鏡）」；生成時穿搭沒有眼鏡則略過 |
| 鏡子自拍 | 拍攝方式選鏡子自拍時，道具欄鎖住（顯示「由鏡子自拍決定」），道具不寫入 |
| 全部隨機 | 面板的「隨機」不會強加道具（重設為全無）；只有道具欄自己的「隨機」才抽 |
| 不適用 | 固定場景位置（馬車、車站）由場景接管；臉部特寫沒有姿勢句，欄位停用；雙人不使用 |
