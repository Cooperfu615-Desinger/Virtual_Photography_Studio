# 蹲姿專屬手部動作 v2

Last updated: 2026-10-17

Status: 七組定義與示意圖已經使用者確認；本機實作，正式輸出模型效果另驗收。

## 公開目錄

- **雙肘靠膝自然垂手**（`squatting-hands-forward`）：雙肘或近肘處輕靠同側大腿前端近膝處，前臂自然向前下垂，手腕與手指放鬆，不要求靠攏。
- **雙手沿腿側自然下垂**（`squatting-hands-outer-legs`）：手臂沿雙腿外側垂下，手肘微彎，雙手在小腿下段至腳踝外側附近，不要求碰鞋或撐地。
- **單手托腮一手自然垂落**（`squatting-one-hand-cheek-one-knee`）：一側手肘靠膝、手掌輕托臉頰；另一側靠膝並向前下垂手，手掌不扶膝。
- **雙手托腮**（`squatting-both-hands-cheeks`）：雙肘分別輕靠同側膝上附近，前臂抬起，雙掌輕托雙頰，手指沿臉頰與下顎放鬆。
- **單手在臉旁比 V**（`squatting-one-hand-v-sign`）：一側靠膝抬手在臉旁比 V、不遮眼，另一側靠膝自然垂手。
- **雙臂搭膝外展垂手**（`squatting-forearms-outward-drape`）：雙臂向左右展開、手肘微彎，前臂近腕處輕搭同側膝上，雙手垂在膝外。
- **雙肘靠膝中央垂手**（`squatting-elbows-center-drape`）：雙肘或近肘處靠膝，前臂向內下方斜垂，雙手靠近在雙膝之間，指尖朝下，不交握或撐地。

肩膀放鬆、左右不固定；不綁定表情、頭部、orbit、服裝、腳跟、膝距或臀部高度。不新增支撐面或指定動作，不自動替寬膝指定手勢。七組維持蹲姿專屬隨機池，四組公開蹲姿皆可組合；原有手動共用例外、服裝／自拍條件與道具互斥不變。

## 合併與相容性

- 五組修改沿用舊 ID，舊完整英文放入 `legacyPromptAliases`；新增外展與中央兩個 ID。
- 公開雙手托腮沿用 `squatting-both-hands-cheeks`，名稱統一為「雙手托腮」。原碰嘴角 `squatting-one-hand-mouth-one-down` 隱藏且退出隨機，保留原英文、ID 與明確還原能力。這是公開目錄的合併，不批次改寫歷史卡片。
