# Z-Image 主輸出：同場拍攝段落 v1

Status: user-approved implementation; external renderer-output retest pending

Last updated: 2026-10-01

## 目的與範圍

把人物正在場景中做的動作與有效光線相鄰呈現，減少「獨立人物描述＋獨立背景清單」的閱讀結構。依使用者接受的室內房間、雜草公園、車廂實測方向實作；不宣稱文字重排一定修復所有模型的人景比例或透視。

只變更一般單人主 Z-Image 與三組日本車廂固定構圖的主 Z-Image。其他五輸出逐字不變：主 GPT、主 MJ、胸上 GPT、胸上 MJ、全身角色照。UI、生成摘要、選項、亂數次數、Saved Cards、匯入／還原與 storage schema 都不變。

## 輸出結構

1. 成品類型。
2. 同場拍攝段落：有效場景 → 已投影姿勢 → 既有可見自拍手勢（一般 Z）→ 有效光線 → 條件式共享環境光連接句 → 原構圖／相機幾何。
3. 人物／體態／髮型／表情／配件。
4. 原服裝內容。
5. 其餘原有內容：精確畫面文字（一般 Z）、攝影風格、光學與成像模擬。

同場段落內使用單一換行分隔來源，不再使用空白段落把場景、姿勢、光線隔開。構圖保持獨立句子與原文字，不把全身與貼近蟲眼混寫成新幾何。

普通路徑有有效場景與有效姿勢才啟用；缺少其一保留原 v1 結構。沒有選光線就不補光。僅有主體光時保留該光線，不虛構環境光。普通路徑有有效環境光時追加：

> She is photographed within the scene's ambient light.

此句不指定新光源、色溫或棚燈。車廂本來已有共享環境光來源，不重複追加。

## 必須保留的來源與邊界

- 從既有 resolved/projected/compacted producers 取文字，不重新抽選、概括人物體態、刪除數值或修改服裝版型／配件。
- 普通 Z 繼續原本獨立關係 anchor 省略、明確手動坐姿物件保留、可見自拍手勢搬入 capture context 的政策。此次不改 anchor 本體。
- 不自動把「床」換成公園長椅，不替人物發明坐墊、支撐面、遮擋或受光方向。選項彼此矛盾時仍交由使用者調整。
- 三組日本車廂搬移完整既有場景、窗景、相機方向與姿勢。選中的人物位置仍接管姿勢與手部；不得回補被接管的整理頭髮或自拍手勢。無位置時保留原有效姿勢，不代選坐姿。
- 保留全部原鏡頭高度／景別／方位／焦段與可見性投影；不新增相機距離、不綁魚眼、不改天空／地面取捨。
- 排除：雙人、特殊主體、角色建模／匯入身份、仰躺 surface-led、其餘固定構圖／月台；這些路徑維持原文字。
- GPT 與 MJ 目前不採用此新段落；不能藉此合併 GPT 結構或改動 MJ 精簡規則。

## 回歸與驗收

`zImageOnLocationBaseline.json` 是改動前的 57 組實際輸出基準，不可用新版重錄覆蓋。新測試比對選項、亂數次數、其餘五輸出 SHA；Z 僅允許可逆的來源重排與上述連接句。歷史相機／場景矩陣透過 test-only inverse 還原重排，再套用原始快照；未知行或來源改寫不能由 inverse 吞掉。

覆蓋房間／公園平視與蟲眼、三車廂、全無、床不代換、手勢、座位接管、字面保留及 JSON／Markdown round trip。執行 frontend tests、Prompt Quality、lint/build、同 seed `200 / prompt-quality-baseline` strict audit；瀏覽器 desktop/mobile 六預覽與五工作區 smoke。

[實際 renderer 的三組實測文字](z-image-on-location-v1-test-prompts.md) 供使用者下一輪生圖；不能以程式測試代替外部影像驗收。提交／推送須另獲授權。
