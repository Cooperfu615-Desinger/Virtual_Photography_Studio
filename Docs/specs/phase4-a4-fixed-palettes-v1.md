# Phase 4 A4 固定配色套裝 v1

基準：37f24aa8fb87633fd87e7fff44258291f862f5c8。依整體授權處理原報告 9 款時尚套裝與 3 款 cosplay；逐筆來源與固定配色見 [審查表](../reports/phase4-completion-2026-10-28/a4/review.json)。

## 決策

保留作者已寫定的全部配色、款式、材質、ID、有序 aliases、明確語意與參考圖。使用既有 meta.colorMode 欄位的新明確值 fixed；目前既有值只有 primary／primary_contrast／primary_contrast_locked，不能假稱已有 fixed 實作。這是 §6.1 一般可配色套裝的十二筆有限例外，其他套裝仍依原規則。

固定套裝的公開衣物描述不加主色、對比色、固定色盤或完整造型色系；全身／近景／外套遮蔽繼續使用原可見性投影。由同一 builder 供給各輸出，雙人每角色各自判斷。選值與既有 RNG 抽樣保持，latent 色值仍存檔，重新生成對固定套裝不生效。摘要不把 latent 主色寫成生效配色。

UI 對固定套裝隱藏不生效的主色與整體色系，沿用既有提示樣式說明原有配色；切換回可配色套裝則恢復原控制。角色 B 的可配色套裝不受 A 固定套裝影響。舊卡公開原文維持，套用重新生成採固定色規則。

## 驗收

十二筆 × 所有主色／完整色系、近景與全身、外套遮蔽、雙人 A／B、舊卡 JSON／Markdown／ZIP。固定 Git 的全無配色輸出為獨立 oracle；變更僅限固定套裝衣物文字、摘要與相應 structured 文字，其他來源／selection／RNG 保持。保護所有非本批來源與歷史基準，使用 aggregate inverse 進行封存回放。完成 AGENTS 全閘門與桌手機提示、切換、套用／複製流程。

抓拍人物匯入遵守既有凍結來源契約：新生成的全身來源包含 fixed 配色；既有 importedPerson 原文與 fullBodyPrompt 不追溯改寫，需由使用者重新生成／重新匯入才採新來源。這是保護舊快照的明確相容邊界，不宣稱舊錯誤原文已被批次修復。
