## 1. 第一版的完成定義

- 普通單人、眼部／鎖骨胸口／腰腹肚臍三目標，使用同一次解析結果，不重新隨機。原有六輸出保持不變。
- 不要求整個目錄全部支援。第一版採下列有限來源及組合；未審核款式維持明確降級，不借用同名、相似材質或衣型的露膚規則。
- 必須分清三件事：來源有局部片語、某個目標能輸出文字、該組合已通過第一版驗收。三者不能互相代替。
- `ready` 只代表已有可輸出的局部證據，允許部分區域仍為 `unknown`。例如上胸布料已知，不等於雙側鎖骨及底下皮膚都可見；不能把它顯示成「完整覆蓋驗證通過」。
- `needs-source-review` 的文字為空，後續 UI 顯示缺資料且不能複製／生成；雙人沒有局部 bundle。不得用一般 Prompt 填補。
- 同一款式在不同部位、外層、穿法下分別判定。知道局部表面時可保留表面，但不得穿透未知外層展示皮膚或飾品。

## 3. 資料收尾：有限的三批工作

不再以「繼續下一批」無限增加衣服種類；先完成下列既定範圍，再接 UI。若現有英文不足，記錄精確缺口；不得為讓測試通過自行新增露膚事實或大改知識庫。

### A. 既有服裝與部位層次收尾

範圍限第 2 節既有款式，不新增一批服裝目錄：

1. 對 13 款胸口上衣及 9 款外套，逐部位核對正常穿法、既有開合／單雙肩、版型及衣襬 modifier 的影響。衣襬穿法不能未經審核就假設改變領口，也不能一律忽略；特別檢查紮衣造成胸口資料被整組阻擋的現況。
2. 腹部維持 3×4 配對、2 種連身開口與 1 種套裝覆蓋基準。驗證正常／高／低／超低腰、外放／紮入及外套中央開口。半紮、打結、吊帶褲、短版衣長等不推定肚臍位置。
3. 對既有長襯衫和連帽外套，審核無額外版型／合身／緊身／Oversize 對局部表面與開口的影響；長短版 modifier 仍暫不擴充。不承諾審核後每個組合都能露膚或 ready。
4. 核對胸口頭髮遮蔽：目前胸口路徑未建立頭髮層，不能將「沒有處理」寫成「不會遮擋」。已知位於該區的髮絲要有局部來源；沒有位置證據不補垂落髮束，也不宣稱皮膚完全無遮擋。
5. 主景別差異的來源保留以真實 `generatePrompts()` 驗證。前批僅補明確鎖定的單件 modifier，不把它誤當全部未鎖定設定都已解析；不能為補局部資料增加抽樣或改寫主輸出。

完成門檻：逐組記錄可見表面、未知區域、停用原因；外層／內層配色歸屬正確；未指定狀態不變成預設裸露；三目標及舊六輸出回歸通過。

### B. 頸部與腰部配件

頸部第一版新增審核 4 組：**街頭風格金項鏈、鎖骨細金屬鏈、皮革 O 環頸圈、水滴寶石吊墜項鍊**。涵蓋短鏈、鎖骨鏈、頸圈與吊墜，不擴充所有 26 組。

腰部審核現有 10 組：三種裝飾皮革腰帶、雙層銀鏈水晶腰鍊、金色細鏈鑽石腰鍊、雙層銀鏈愛心腰鍊、愛心垂墜銀腰鍊、銀色水鑽蝴蝶腰鏈、肚臍環、馬甲束腰。

- 配件各自判定位置及相對衣物的層次。戴在衣服外的束腰不能套用「只有皮膚露出才可見」的肚臍環規則。
- 腰帶位於 hips 的來源不能迫使肚臍特寫拉遠至整片臀部；確認畫面外就省略，位置不足則保留未知，不能改位置來湊結果。
- 長鏈只描述來源支持的局部，不保證整條鏈或末端吊墜入鏡。未確認佩戴在衣服內外時，不自行假定。
- 未審核配件的保護範圍應按可能影響的子區域與層次處理；現有「先於所有衣物的整部位 barrier」不能宣稱是完成的精確模型。

完成門檻：這 14 組都有正向／遮蔽／未知／畫面外的適用案例或明確不可推定紀錄；隱藏飾品不鑽透衣服，不因任一配件而無條件丟掉已確認的外層表面。來源不充分的項目仍不得標成完整可用。

### C. 局部膚質與成像

有限候選清單如下；只抽取已選原文可追溯且適用局部的片語：

- 膚質：既有 3 組通用肌膚來源，檢查胸口／腹部可見區適用性；不新增雀斑、痣或濕身。
- 主體光線：審核目前 25 組 `lightDirectionId`，逐一列出安全片語或省略原因。不保留完整臉孔、人物輪廓或窗戶／地面；光源方向不等於相機角度。
- 色調首批 4 組：富士 Provia 清透明亮、日系亮膚高彩濾鏡、日系雜誌高彩銳利、高階黑白灰階。
- 光學效果首批 3 組：霧化高光 Bloom、柔焦濾鏡 Soft Focus、色差 Chromatic Aberration。
- 環境光首批 3 組：室內冷白環境光、高調純白攝影棚、柔霧美妝攝影棚；僅保留無場景物件的照明／色偏片語，不新增房間或白背景。

完成門檻：runtime 傳入同一次已解析來源；每個安全片語可回溯；未審核效果省略並有內部診斷，不單靠光線讓空的部位變 ready。不解決原主輸出的成像效果互斥問題。普通選項不能因為未接入而被宣稱已保留。

## 5. 進入 UI 階段的關卡

1. A／B／C 三批逐項更新為已驗證或精確列明不可推定；不能以測試總數取代矩陣驗收。
2. 三部位各有可靠的可用基準；胸口及腹部包含衣料覆蓋與來源明確的局部開口，眼部包含無遮擋及眼鏡／眼布。另有組合未知與完全缺資料案例。
3. 同次解析、零新增 random、原六文字／selection 不變；特寫主景別不丟局部必要來源。來源改動、未知 modifier、多層配色均有回歸。
4. 局部來源／renderer 改動依 AGENTS 跑 focused、Prompt Quality、全套 test/lint/build、同 seed/count strict audit、五工作區 browser smoke；新資料若需改知識庫另走 sync gate。
