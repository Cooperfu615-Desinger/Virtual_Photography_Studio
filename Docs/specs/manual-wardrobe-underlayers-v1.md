# 一般單人穿搭的手動內搭

「B 神情姿態」選取相容指定動作的「雙手上拉衣襬」或「嘴咬衣襬，雙手背後」後，在手勢旁選上身內搭。「C 穿搭設定 → 上下身單件」在外褲的腰線明確選為「超低腰」、相容的「扣子解開拉鏈微開」或「外褲褪至大腿」時顯示下身內搭。下身腰線留在原位，下一列放下身內搭與配色。上下身內搭均從「無」開始，選了單品才在同列顯示色票入口；手機也保留單品與配色並排。

- 上身使用目錄中的比基尼上身、運動型內衣、蕾絲胸罩、小三角細繩比基尼上身、X形胸貼與創可貼造型胸貼。
- 下身使用比基尼下身、蕾絲丁字褲、棉質低腰三角褲、窄前片細繩蕾絲丁字褲與窄前片細繩比基尼下身。腰線描述作用在外褲。超低腰依內層款式顯示上緣、側帶或綁帶；解扣露出局部內層布料。「外褲褪至大腿」限一般單人手動選擇，適用外穿長短褲，排除吊帶褲、內褲及泳褲。整圈外褲腰頭停在大腿中段（髖部與膝蓋的中點），選定的內搭穿在原位、完整可見；內搭選「無」時只寫外褲位置。
- 兩個新手勢都須手動選取，沿用指定動作的自由手部資格。雙手上拉時將衣襬拉到頸根，衣料沿鎖骨聚在胸部上方；嘴咬款咬住上衣前襬中央，整片前幅從嘴邊沿一道連續三角形皺褶向兩側展開，衣料高收在鎖骨處。選了內搭才帶入該件短名稱及清楚可見的描述，最後以雙手放在背後收句。無上身內搭時只描述動作。未指定主單品時，在同一次生成選定一件相容上衣或外褲。完整造型、雙人、角色卡、特殊主體、固定構圖及觀察式抓拍沿原模式處理。
- 切換條件時，編輯器保留有效的手動單品與配色供切回使用。生成與收藏只記錄當次有效內搭。單品沿用既有目錄 ID；編輯狀態與 Markdown v1 接受四個可選欄位。既有收藏、單品 ID、儲存鍵與空設定不需要遷移。
- 七組輸出共用同次選擇。內搭隨其主衣物的原有投影；MJ 採單品短名稱，Grok Imagine 沿用完整穿搭，全身角色照保留穿搭與自然站姿。跨模型實際出圖另行評估。
