# 跪姿動作目錄 v2

Last updated: 2026-10-02

Status: 使用者核准的實作契約；實際生圖效果另行驗收。

## 公開目錄

沿用原有 ID，七組公開肢體變化如下。頭部、神情及朝向維持獨立；四足以外不新增手部綁定。

| 名稱／ID | 必要身體結構 |
| --- | --- |
| 跪坐 `kneeling-seiza` | 雙膝併攏著地、臀部坐在腳跟上、軀幹直立。 |
| 分腿跪坐 `kneeling-wide` | 雙膝自然分開著地，小腿往後折在臀部兩側，臀部落在兩腿之間的地面，軀幹直立。 |
| 前傾跪姿 `kneeling-forward-lean` | 高跪姿、雙膝著地、臀部離開腳跟，上身從髖部向前傾；手部仍獨立。 |
| 四足跪姿 `kneeling-all-fours` | 雙膝及雙掌或雙肘／前臂著地、臀部抬高；手部支撐決定肩胸高度及軀幹角度。 |
| 直立端正跪姿 `kneeling-upright-poised` | 高跪姿、雙膝著地、大腿接近垂直、髖部在膝蓋上方、臀部離開腳跟、軀幹直立。 |
| 側坐跪姿 `kneeling-side-sit` | 臀部降到折疊雙腿旁邊、軀幹放鬆直立。 |
| 單膝前跨跪姿 `kneeling-one-knee-forward` | 一膝著地、另一腿向前跨且膝蓋彎曲。 |

`kneeling-side` 跪姿側身退出一般選單及隨機池，保留原有 ID、完整英文及投影供舊卡、匯入與明確還原。其餘已退役跪姿同樣保留。

## 四足支撐綁定

- 新進入四足跪姿時，手部預設 `hands-palms-planted-ground` 雙掌撐地。手部選單只列雙掌及 `hands-elbows-planted-ground` 雙肘撐地。
- 雙掌：手臂伸展、肩胸較高，軀幹大致平行地面。
- 雙肘：雙肘／前臂支撐、雙手自然放在前方，肩胸降低，軀幹從髖部向前下方傾斜；臀部仍抬高。
- 手動切換雙肘後，改其他設定或重新生成保留該選擇。四足手部隨機只在兩個支撐中解析，景別不改變支撐選擇。
- 新選取四足時清空道具動作；四足期間道具控制停用。隨機道具不得接管必要支撐。離開四足時清空仍沿用的雙掌／雙肘選擇，不新增儲存欄位或自動還原先前的普通手勢。
- Saved Cards、標準 Prompt 匯入及預覽回填走明確還原流程，保留雙肘或歷史明確手勢，不能因進入四足而重設為雙掌。歷史不相容明確手勢／具體道具仍依原契約還原；其已存 Prompt 不批次改寫。選單保留當前歷史值，直到使用者改選。
- 四足未指定手部且沒有具體道具時，生成器預設雙掌；`任意` 也不能省略必要支撐。支撐先於裁切解析；不因地面在畫面外而重新抽選手部。

## 來源與六輸出

動作資料定義在 `webapp/src/lib/engine/poseComposerOptions.js`，不以 Markdown 同步新增另一份資料庫。四足的 `supportVariants` 定義每種支撐的完整來源及八種景別投影；`kneelingSupport.js` 共用支撐 ID、選取綁定、選單投影和來源解析。

GPT、Z-Image、MJ 從同一 resolved pose 取得投影後的來源。GPT 完整保留有效來源，Z/MJ 沿用各自組裝契約；不新增三套獨立動作文字。胸上／腰上省略腿、臀與地面接觸，四足仍保留該支撐所決定的肩胸高度及軀幹傾斜。前傾與高跪保留既有上半身片語。牛仔中景／全身／固定構圖／未限景別保留完整來源；頭肩及臉部裁切沿用省略規則。

兩組胸上輸出沿用 [同一拍攝狀態契約](chest-up-same-state-v1.md)，重新投影同一次解析的四足來源，固定 `4:5`。全身角色照維持自然站姿、單人、`9:16`，不繼承跪姿。固定場景位置仍優先接管姿勢；不修改車廂／月台預設、其他姿勢、鏡頭或儲存 schema。既有英文變更保留 `legacyPromptAliases`，包括支撐變體來源，供標準 Prompt 解析。
