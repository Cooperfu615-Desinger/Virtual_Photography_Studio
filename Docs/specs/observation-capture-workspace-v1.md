# 觀察式抓拍整合 Prompt 工作台 v1

日期：2026-10-19。狀態：使用者已確認本機驗收通過，授權提交並推送本批。

## 核准範圍與介面

沿用使用者核准示意圖與接管／衝突方向。Prompt 工作台 A–F 上方提供「一般拍攝／觀察式抓拍」。獨立抓拍導覽退休，舊獨立產生器、資料與 storage 保留；舊 page mode 導向工作台。

面板由上而下：

1. 拍攝人物：角色卡縮圖與選單，和 A 共用選值；穿搭沿用 C，提供「調整穿搭」。
2. 「導入單人／雙人與穿搭」停用入口，標示後續開放；第一版僅支援現有單人角色卡。
3. 場景／生活動作。
4. 察覺鏡頭／觀察位置。
5. 前景遮擋／鏡頭。
6. 環境光線／成像質感。
7. 本次組合摘要、重抽隨機項目、全部設為隨機。

每項可固定／隨機；手動選擇即固定。重抽只改未固定項；全部固定時停用重抽。全部設為隨機只解除固定，不立即重抽。沿用既有 8 場景、9 動作、3 察覺、6 位置、6 前景、4 鏡頭、6 光線、5 質感；前景與質感另有「不額外添加」。桌面成對欄位，640px 以下單欄及上下排列操作按鈕。

## 接管範圍

| 區域 | 抓拍模式行為 |
| --- | --- |
| A 人物 | 保留角色卡身份、外觀設定；不採用角色卡自己的攝影方向，避免與抓拍光線／質感衝突 |
| B 神情姿態 | 由生活動作與察覺狀態接管姿勢、頭部、表情、指定動作及動作卡 |
| C 穿搭 | 保留既有選值與角色卡 layer 規則；重抽抓拍不連帶重抽衣服 |
| D 場景環境 | 抓拍場景與光線接管；原場景匯入與光向不進入有效輸出 |
| E 攝影成像 | 接管影像類型、風格、角度、環繞、鏡頭、光圈、快門、光學效果、底片、相機；保留比例與全身／膝上／腰上景別 |
| F MJ | 沿用目前參數，仍只作用於主 MJ |

被接管欄位的原始選值保存，切回一般拍攝即恢復。雙人、特殊主體、固定構圖與不相容景別不進入此模式；未選角色卡時可進入面板選卡，但不生成輸出。

四主輸出共用同一組解析結果；GPT 保留有效完整來源，Z／MJ 依各自規範壓縮。GPT 胸上沿用同一拍攝狀態，使用九動作的胸上片段與場景可見性投影。全身角色照仍是單人、9:16 自然站姿 reference，不帶入抓拍場景或動作。

核准新增的 integrated-only 來源：靠欄杆動作只配公園步道，場景加上 `with a railing beside the park path`。其他模式及舊獨立產生器來源不改。

## 衝突與解析

固定選值優先，先收集全部固定項再回溯搜尋未固定項；不能組合時顯示原因並停止生成，不偷換固定項。不相容選項在下拉選單停用並附原因。

- 貨架動作／間隙／前景只用於書店或便利商店。
- 店面玻璃適用咖啡廳、商場、便利商店、街角或商業街；玻璃位置只配玻璃前景或無額外前景。
- 低位桌緣／座椅觀察與欄杆前景限咖啡廳或公園。其他前景遵守室內外類型。
- 公園靠欄杆限未察覺；看手機、瀏覽貨架同樣保持專注原文，限未察覺。
- 遠距長焦位置限 85／135mm；手機位置與手機運算質感限手機鏡頭；小型相機顆粒排除手機。
- 動態模糊限走動、回頭、整理頭髮或衣服；反射質感要求玻璃位置或反射前景。
- 咖啡暖光、便利店螢光、商場／車站／書店冷光、街角／公園陰天、商業街／街角黃昏、公園樹影各自限制場景。

## 儲存與相容性

新增 `captureMode` 與 `observationCapture`，後者保存 version、seed、八組實際選值和固定旗標。一般模式快照不新增這兩個欄位。JSON Saved Cards 保留完整快照；Markdown 匯出另帶抓拍選值註記，重新匯入可恢復設定。只複製公開 Prompt 的純文字無法保留固定旗標；完整回填請使用收藏或匯出的 Markdown。

既有歷史 Prompt、角色卡 identityAndBody、public output mapping、舊來源 ID／storage 不改。Public contract 1.61.0。既有凍結測試僅從歷史輸入 hash 排除新增且未啟用的預設欄位，原輸出雜湊與 fixture 保留。
