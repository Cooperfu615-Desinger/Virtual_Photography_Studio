## 公開動作與參考版本

| 名稱／保留 ID | 必要結構 | 採用示意圖 |
| --- | --- | --- |
| 自然蹲姿 `squatting-natural` | 雙膝舒適彎曲，臀部接近腳跟但離地，腳距自然、可微幅錯開，上身自然稍前傾。 | 最初自然蹲姿 B 圖高度。 |
| 收攏低蹲姿 `squatting-side` | 雙腿與雙腳靠攏，大腿接近小腿，臀部充分下沉但離地，上身靠近大腿、肩背放鬆。 | 最後降低臀部的版本；不再追求幾乎貼地。 |
| 身體前傾蹲姿 `squatting-forward-lean` | 雙膝舒適分開、臀部低沉，上身從髖部輕微前傾，肩背與頸部放鬆。 | 第一版，拒絕後續誇大探身版本。 |
| 寬膝低蹲姿 `squatting-gangster-wide-knee` | 膝蓋向外，腳距適度加寬、腳尖順著膝蓋，臀部低沉在雙腿之間且離地，上身稍前傾。 | 成功生成的第一版 A 圖開膝程度，不採後續誇張化。 |

四組均以日常街拍的放鬆低蹲為目標，允許腳跟自然落地或輕抬，不強制全掌貼地。腳部微幅錯位是允許的變化，不強制左右不對稱。自然與前傾可有細微差異，不為區分而添加強烈探身。示意圖的手搭腿、視線、衣著、背景及相機方向不是動作來源；不新增縮圖選取介面或指定動作。

## 退役與相容性

- `squatting-one-knee`、`squatting-low-one-leg-forward`、`squatting-knees-together-low` 改為隱藏／非隨機，原英文及投影保持不變。其他既有退役項目同樣保留。
- 收攏低蹲取代側身蹲姿的內容，沿用 `squatting-side`；不再指定軀幹轉向鏡頭。寬膝名稱移除「深蹲／流氓蹲姿」，ID 保留。
- 四組舊完整英文置於 `legacyPromptAliases`，純文字匯入仍能辨識原 ID；Saved Cards／JSON／預覽回填沿用穩定選值。舊儲存的 Prompt 原文不改寫，套用選值重新生成時採新版。
- 手部、頭部、表情、orbit、道具、接觸／支撐及其互斥政策不改。接觸／支撐仍只有全無公開選項；不重新開放退役支撐面。

## 共用來源與現行六輸出

唯一動作來源為 `webapp/src/lib/engine/poseComposerOptions.js`。四主輸出（GPT、Z-Image、MJ、Nano Banana）共用解析後的來源，不增加各 renderer 專用改寫。

- 自然、收攏、前傾：胸上／腰上只保留輕微前傾、放鬆肩背／頸部；不輸出膝腿、臀部高度、腳跟或地面接觸。
- 寬膝：核心是下半身輪廓，沿用胸上／腰上省略肢體來源的投影，姿勢基底由既有景別規則處理。
- 臉部／頭肩沿用省略；牛仔中景／全身／未限景別／固定構圖沿用完整肢體來源。八種 bucket 均明確定義。
- GPT 胸上沿用同一拍攝狀態及 4:5，從同一次來源重新投影。全身角色照保持自然站姿及 9:16，不繼承蹲姿。已移除的 MJ 胸上不恢復。
- 指定動作、姿勢卡、固定場景接管及雙人既有排除不改。Public output contract `1.57.0`；儲存 schema 不變。
