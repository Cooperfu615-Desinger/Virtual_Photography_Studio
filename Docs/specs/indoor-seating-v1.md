# D 區「坐在哪裡」第一版實作計畫

已核准實作 · 2026-11-05 · 盤點基準為本機 main `358034c5`

**使用流程。** B 區選「微微前傾」，D 區選「日本學校教室 → 椅子」，完整姿勢句為 `She sits on a chair, leaning slightly forward.`。若先選教室，D 區也看得到「坐在哪裡」，並提示到 B 區選擇坐姿。場景沿用原本的描述，椅子的接觸關係由姿勢句表達。

## 一、範圍與介面

第一版涵蓋一般單人拍攝、手動選定的 83 個具名室內場景與 14 個坐姿指定動作。以場景 ID 辨識，因此直接選到室內場景即可，不必先操作「場景屬性」。固定構圖、匯入場景、觀察式抓拍、雙人及具有獨立姿勢來源的模式沿用各自的流程。

| 使用情況 | D 區行為 |
|---|---|
| 已選室內場景，B 區尚未選坐姿或使用隨機動作 | 在場景欄下方顯示提示「選擇坐姿後可指定坐在哪裡」。 |
| 已選室內場景與可指定坐具的坐姿 | 單選，預設「未指定」。列出該場景提供、且該動作適用的坐具。選項順序沿用場景清單。 |
| 切換到另一個場景或坐姿 | 若同一選項仍適用則保留；若不適用則回「未指定」，並顯示一次簡短原因。 |
| 已選四個固定地面動作之一 | 以唯讀狀態顯示「此動作坐在地面」。適用的和室顯示「此動作坐在榻榻米上」。 |
| 場景為隨機、全無、戶外，或由其他模式接管 | 停用坐具。一般手動切換清除失效選值；具有既有模式還原機制的路徑沿用該機制，休眠值不參與生成。 |
| D 區清空、全無、隨機或工作台全部隨機 | 坐具回「未指定」，不額外抽坐具。使用者保持有效場景、動作與坐具鎖定而只重抽其他欄位時，保留有效坐具。 |

## 二、場景與姿勢配對

以[83 個室內場景逐項清單](indoor-seating-scenes-v1.md)為底稿。使用穩定場景 ID 對應坐具，基本名詞共享，不由英文描述臨時擷取物件。原清單的 13 種物件中，「床」拆成「床邊／床上」兩個可保存的選值；地板仍是同一選值，在兩個已確認的榻榻米場景顯示「榻榻米」。所有場景可保留「未指定」。新場景尚未編寫清單時先只提供「未指定」。

下表是供本次確認的**首版相容表**。每列再與目前場景的坐具清單取交集。這些是產品選項範圍，目的在於保留姿勢原有的腿部、軀幹和承重關係。

| 坐姿 | 可提供的坐具或位置 |
|---|---|
| 自然坐姿、微微前傾 | 允許該場景清單的全部坐具。 |
| 雙腿自然伸展 | 椅子、長椅、沙發、床邊、床上、講台、台階、坐墊、墊子、地板。 |
| 盤腿坐姿、雙腿屈起 | 床上、沙發、講台、坐墊、墊子、地板。 |
| 隨性癱坐 | 椅子、沙發、長椅。 |
| 翹二郎腿 | 椅子、凳子、長椅、沙發、床邊、桌子、檯面、講台、台階、箱子。 |
| 單腿屈起坐姿、雙腿側放坐姿 | 長椅、沙發、床上、講台、坐墊、墊子、地板。 |
| 開闊自信坐姿 | 椅子、凳子、長椅、沙發、床邊、桌子、檯面、講台、台階、箱子。 |
| 折腿低坐・雙掌後撐、單腿屈起・單掌後撐、低坐抱膝、低坐貓群冷淡氛圍 | 固定地面，保留已指定的手、腳、臀部與地面的相對位置。 |

床邊用 `on the edge of the bed`，床上用 `on the bed`；腳的位置由原動作決定。一般地板用 `on the floor`，日式和室和生活感日式榻榻米房間用 `on the tatami floor`，坐墊用 `on a cushion`。講台採可坐的平台語意 `on a platform`。桌子採 `on a table`。例如「白色床鋪＋盤腿」可選床上，「白色床鋪＋自然坐姿」可選床邊或床上。

固定地面動作的唯一自動文字調整限定於**明確選定室內場景與這類動作**、且地面適用時。將原姿勢中的地面接觸詞對應為 floor 或 tatami floor，一致處理多個著地部位，不再附加第二個坐具。像「白色床鋪」這種以床面填滿畫面的場景，維持原動作的地面要求，提示改選場景或姿勢；不將貼地動作自動搬上床。

## 三、實作順序

1. **先建基準。** 實作當天確認最新 main 與其他 session 的修改；用固定種子、相同選值與景別記錄修改前七組文字、有效選值與抽選次數。先寫教室、臥室、和室、地面動作和舊收藏的回歸案例。
2. **建立選項及解析規則。** 建立獨立的場景坐具對照與坐姿相容表，以現有場景及指定動作 ID 為鍵。使用新的可選欄位保存坐具或床的位置。接上清空、切換、匯入及還原時的有效性檢查，不啟用退役的 poseAnchorId。場景原文維持原來源。
3. **接入姿勢組句與介面。** 在同一次生成中解析一次有效支撐，從指定動作的核心、腿部、手部與承重子句組裝完整姿勢，再讓各輸出按自己的景別規則取用。第七組取完整姿勢，胸上取原本可見的片段，全身角色照維持自身站姿。D 區和引擎共用同一份有效選項判定。先用代表場景走通介面與生成，再核對 83 筆對照。
4. **接通保存與完整驗證。** 新收藏保存明確選值，還原後仍能區分床邊／床上；舊卡缺少新欄位視為未指定，未知選值採相同處理。核對 Saved Cards、Markdown、ZIP、套用預覽、複製與 DLL 來源。歷史測試只做必要的相容銜接，保留原歷史基準。
