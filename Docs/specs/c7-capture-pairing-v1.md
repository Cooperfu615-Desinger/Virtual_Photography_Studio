## 目的與界線

只限一般 PAGE1 單人、預設目錄的隨機候選。手動選值優先，矛盾手選也不改寫；全無、未知 ID、自訂 library、雙人、角色卡／特殊主體、抓拍、固定構圖、匯入場景與躺姿沿用現況。不更動 UI 選項、正式目錄、ID、renderer 或舊收藏原文。艾爾莎場所可達性保持，PAGE2 舊匯入／J12／P5b 不併入。

目前沒有季節欄位。季節判斷僅來自已審閱的地點與環境光英文；以 `captureCompatibilitySources.json` 封存全部 27 風格、155 地點、37 環境光、32 人物光、7 快門來源（含全無），ID 與完整英文同時匹配才套規則。未知／改寫來源不推論。

## 明確互斥與責任

1. 盛開向日葵花田與雪地冷光／冬季灰冷不隨機配對。櫻花、海灘、泳池不憑名稱套夏季；冬季可用場景仍保留。
2. 風格明示日光／夜間時，與相反時段的地點／環境光避免隨機配對。現行夜間地點為夜間家庭派對。川內倫子、高橋洋子、青山裕企日光；艾爾莎夜間。來源逐筆分類及保留理由見 JSON。
3. 風格高調光（橫浪修、川內倫子）與明示低調人物光互斥；風格低調光（上田義彥、保羅）與高調人物光互斥。場景暗與人物受光亮可以共存，不把環境光當人物光。
4. 保羅的慢門細緻感與 1/1000s 明確完全凍結動作互斥。1/250s 的大部分銳利／細微動態並非完全凍結，保留。柔焦、濕版、銳利不直接推論快門速度。

隨機地點尊重手選環境光／風格；隨機風格尊重已選地點與手選環境光／人物光／快門；再選環境光、人物光與快門時尊重既定風格。前兩批夜間派對及黑白／彩色規則同時生效。保留原抽樣順序及 picker，無重抽或補抽；空快門與原始 random 值經既有正規化後仍為全無，本批不新增快門隨機能力；可見修正為手選 1/1000s 時，隨機風格避開慢門風格。候選相容函式保留對稱檢查，但不宣稱有新的隨機快門 UI。手選風格與手選成像的黑白衝突仍保留。

## 合理例外

自然光不一定日間，黃昏／夕陽不強迫歸日夜；石田／奧山的夏日光感屬風格氣氛，沒有完整場景季節指令。閃光與環境光、柔光與輪廓光可同時存在，沿用 A6 人物光責任。風格導言與完整英文保留，不刪主觀氛圍、不重寫 renderer。成像來源內建 CCD 閃光／晃動、VHS 色差屬其他欄位責任，不擴張成所有成像／快門／光學互斥；列為保留例外及可能的後續產品決策。黑白成像仍可描述物體與實體燈光的原有顏色。

## 遷移與驗收

先封存 3,936 組修改前基準與兩階段獨立預期，再實作季節、驗收，最後加入風格光線／快門。獨立預期只在 Git 原引擎的候選 predicate 插入審閱關係，保留原 picker，不讀產品 helper。基準含 2,200 手動案例、276 排除案例、全地點與 11 景別、預覽排除、收藏 Markdown 往返。

預期季節階段 170 組改變、整合 320 組改變，其中 96 組地點改選。地點不變時只能改風格、成像及既有光學連動、環境／人物光／快門，RNG 次數與全身角色照保持。地點改變時允許原有場景條件帶動其他選值；不得新增亂數呼叫，本基準仍全數 RNG 次數相同。不能將此說成所有任意場景改選都不影響後續選值。
