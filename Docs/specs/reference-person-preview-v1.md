# 單人「參考圖人物與穿搭」預覽 v1

核准日期：2026-10-14。基底：`origin/main` 的 `9629c4b`（官方規範修正與全域全無均已合併）。

## 範圍與操作

- 附加指令列提供獨立開關「參考圖人物與穿搭」，可搭配既有四種互斥附加模板。清除附加只清模板；再次點參考圖開關可關閉參考模式。
- 一般單人支援普通場景、固定構圖、現有六組非空白輸出。雙人、角色卡、特殊主體、自訂身份及沒有本次 resolved source 的歷史純文字資料不提供此功能。
- 只影響預覽與複製，不改原始 Prompt、摘要、鎖定、隨機結果、加入最愛、DLL 來源或儲存格式。使用者需在外部生成工具附上參考圖片；本功能不提供上傳、圖片辨識或 provider 原生參考圖參數。
- 新 preview object（含重新生成、設定變更、回填）與離開工作區會重設參考模式及附加模板。關閉參考圖模式恢復原始文字；保留目前選用的其他附加模板。

## Prompt 契約

這是使用者明確開啟的 renderer 投影例外，不更改一般輸出的完整保留契約。

- 從同一次 resolved context、character、wardrobe 建立獨立投影，不從 locks 重新生成、不消耗隨機數、不以正規表示式刪除完成的 Prompt。
- 移除選定的體態、五官、皮膚、髮型、髮色、髮絲整理與全部服裝配件來源（含完整造型帶入的外觀）；替換為一位成年參考圖人物。
- 指示參考圖決定身份、臉部、身體比例、皮膚、頭髮、妝容、服裝、配色、材質、鞋襪與配件；不指定固定年齡、族裔或額外美貌描述。
- 保留有效神情、姿勢／頭部／視線、場景、支撐、道具、光線與攝影設定，沿用各 renderer 既有投影。一般手勢仍用原來源；服裝／配件互動僅在參考圖有該單品時執行，否則放鬆手勢，不補造單品。
- 胸上保持 4:5 同狀態，完整角色照保持 9:16、自然站姿與乾淨均勻光。MJ 僅主輸出保留現行 F 參數與景別比例；不恢復已移除的 MJ 胸上。Z 可見文字保留。
- 原始輸出不變；四個附加模板的排他行為不變。兩個 snapshot 模板在參考模式下明確指定人物／服裝來自參考圖，場景沿用描述。
- 實際模型是否接受參考圖、保持一致性及生成多張，需在外部工具實測；此次只驗收文字與產品操作。

## 實作邊界

`engine.js` 在一次解析完成後，以 `referencePersonPreview.js` 的 WeakMap 註冊 lazy renderer；key 是該次結果的 structured object。F 區淺拷貝保留此 key，生成文字時再套當下 F 值。JSON／Saved Cards 不序列化此登錄，也不新增 storage 欄位。首次開啟才渲染參考版，後續使用同一 resolved source 快取。

`Page1Workspace.jsx` 保持獨立暫存開關與模板選值，只有展示卡片使用參考投影；DLL 仍直接讀原 preview。`promptAppendices.js` 僅在明確參考模式下調整兩款 snapshot 的指代。
