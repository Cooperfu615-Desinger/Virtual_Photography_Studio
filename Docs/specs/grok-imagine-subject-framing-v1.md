# Grok Imagine 人物大小與畫面中位置

2026-11-23 工作台首版。在 E「攝影成像」的「構圖與視角」中，兩個手動欄位接在景別之後。

| 欄位 | 選項 | 責任 |
| --- | --- | --- |
| 人物大小 | 預設、小、極小、微小 | 預設沿用景別；小、極小與微小分別以完整人物占畫面高度約三分之一、五分之一、十分之一為 Prompt 目標。 |
| 畫面中位置 | 不指定、置中、靠左、靠右、靠下、貼底 | 靠左／右沿畫面三分區留出另一側空間。靠下與貼底在水平方向居中，人物輪廓下緣分別接近從畫面上方量起的 90% 與 98%。貼底保留完整人物，下方只留一線空隙。 |

兩個欄位可分開使用。只在一般單人明確選中「全身鏡頭」時套用至 Grok Imagine。角色卡、專屬主體、固定場景、觀察式抓拍、參考人物預覽及其他景別沿用原構圖。維持原本的景別、焦段、視角、人物朝向和畫幅設定，追加人物占比或位置句子。比例是模型的取景目標。

只有非預設選值寫入工作台和 Saved Cards 的可選欄位，支援 Markdown 和 ZIP 還原。舊收藏缺欄位時沿用原畫面，已存 Prompt 原文保持。「清空構圖」重設兩欄，構圖隨機與整體生成的既有亂數流程不抽新欄。暫時切到不適用的景別或模式時保留原選值，回到合適條件後恢復。

使用者確認「小」的參考成圖大小可用，並以 Grok Imagine 試圖驗收「極小」與「微小」的人物比例。模型未能穩定貼近下框，「貼底」保留為構圖提示，實際是否貼底不列為出圖驗收條件。

在固定坐姿、場景、畫幅與其他選項下，比較「極小＋靠下」「極小＋貼底」「微小＋貼底」，並驗證既有選項、非目標輸出及亂數抽取。桌機與手機驗證了 Prompt 預覽、複製和收藏套用。
