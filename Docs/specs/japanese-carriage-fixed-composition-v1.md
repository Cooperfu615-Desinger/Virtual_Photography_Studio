## 場景與窗景

| ID / UI 名稱 | 場景核心 | 相機方位 |
| --- | --- | --- |
| `japan-carriage-bench-front` / 電車車廂正面長椅視角 | 從長椅對面正向拍攝，藍色布面長椅、寬車窗、窗框、滑門、吊環、路線圖與小廣告；人物姿勢獨立決定 | 正面，顯示且停用 |
| `japan-carriage-side-aisle` / 電車車廂側面走道視角 | 人物附近側拍、走道向連接門收束、長椅／扶手／吊環延伸、少量坐站乘客；同行者拍攝感，不新增拍攝者人物 | 左前、左側、右前、右側 |

三組共用「固定場景背景狀態」四種窗景：都市、住宅區、鄉間、海邊，以及既有全無。窗景只描述車窗外，不把車內改成戶外；不指定列車行駛、不強制拖影、不指定車型或路線。背景只在裁切及乘客遮擋允許的位置可見，不保證完整車窗。

## 控制與相容性

- 三組都開放構圖景別及焦段，其他固定構圖保持原接管規則。俯仰沿用既有可用性；光學效果接管與 9:16 預設沿用固定構圖契約。
- 三組的 orbit 是相機相對人物方位，不套用月台的 subject-facing 例外。車廂實體配置穩定，但相機換側可以改變畫面中的左右關係。
- UI 以純投影限制／顯示有效方位，不修改原 orbit lock；離開這三組恢復原可選範圍與潛在選擇。非法舊匯入值在生成時正面長椅解析為正面、走道解析為左前；有效 selection 保存解析後方位。
- Pose Composer／特殊動作／自拍仍遵循既有相容性及接管優先權，不改姿勢或手部規則。人物姿勢不由場景強制坐下；頭部動作仍獨立。
- 保留原固定場景拍攝型態及演出狀態。車廂的攝影師拍攝文字不要求臉和服裝完全無遮擋；其他場景不變。
- 不新增 storage key、不移除 ID、不改 renderer 公開映射。背景 ID 為 `carriage-window-urban/residential/countryside/coastal`，只對 `japanese-carriage` group 有效。
