# Z-Image 全身相機呈現規則 v1

日期：2026-09-18（距離語意補正）

狀態：六組呈現規則已在本機實作，程式驗證通過；瀏覽器驗收 PARTIAL、正式 runtime 影像實測待使用者確認。不含 commit／push。

## 範圍

只適用一般 PAGE1 單人主 Z-Image、有效 composition bucket 為 fullBody 的輸出。沿用 scene-integrated 既有排除：雙人、固定構圖、專用角色、角色卡／身份匯入、仰躺 surface-led 與衍生輸出。其他景別與獨立工作區保持原樣。

不更動 UI、資料庫、locks、儲存格式、摘要、景別解析、相機角度解析或所選焦段。場景地面／天空刪減與上方場景 v2 仍依原始有效 angle 分組，不使用本文件的六組呈現方向取代它們。新增的距離數字是 Prompt 中的軟性視覺尺度提示，不是新的鎖定值或相機控制。

## 六組呈現方向

| 分組 | 既有選項 | 全身描述責任 |
| --- | --- | --- |
| 自然全身 | 平視、肩部、腰部、膝蓋 | 保留現有高度短句，以自然比例完整呈現，不額外強迫局部放大。 |
| 自然全身＋傾斜 | 荷蘭角 | 保留 tilted frame，補充畫面傾斜；不擅自指定相機高度。仍屬自然全身組。 |
| 低角度全身 | 地面 | 相機近地、與人物保持距離並向上拍攝，完整人物、較溫和透視。 |
| 貼地近距離蟲眼 | 蟲眼 | 近距離陡峭仰拍、近前景放大、遠處縮小；不自動指定魚眼或改寫焦段。 |
| 高角度全身 | 高位俯視 | 約 1.5–2 公尺的人像距離，從人物上方斜向下拍攝；人物仍主導畫面，上方面向鏡頭的身體平面略為突出。 |
| 鳥瞰 | 鳥瞰 | 約 3–5 公尺的高處並向後拉開，斜向俯看；人物比例較小，周圍空間布局清楚可見。 |
| 正上方 | 正上方俯視 | 約 1–2 公尺的正上方位置，以 90 度垂直朝下；畫面扁平、圖形化，沒有斜向觀看。 |

全無／未知 angle 不新增預設視角。自然全身只有一組，荷蘭角是其中保留的旋轉差異，不是第七組。

## 姿勢與文字邊界

- 只替換相機 angle 句；既有方位／側身幾何、姿勢、服裝、場景、光線及成像不動。
- 站姿蟲眼沿用使用者實測方向：腳部與小腿近前景較大，軀幹與頭部向上遠離。不得強制赤腳、正面、雙腳落地或改寫站姿動作。
- 非站姿／未指定姿勢使用最近可見身體區域的近遠透視描述，不強制人物站起、不推導支撐點、不固定腳部最近。
- 低角度、俯視與頂視句不自行指定站姿或正面。完整人物指頭至腳的可見範圍，不要求身體伸直。高位／鳥瞰／正上方只使用約略距離作為模型的空間尺度提示，不把公尺數當成硬性拍攝參數。
- 不新增鏡頭控制項、不自動綁魚眼、不刪除使用者選的光學效果。既有極端視角與長焦等組合仍可能有視覺張力，本輪不擴大成相容性修正。

## 回歸設計

修改前凍結上方場景 v2 工作區的 deterministic outputs／selection／RNG hashes。覆蓋十種有效角度與全無、五種姿勢、非全身景別、各排除路徑、方位、光學與既有 230 組場景案例。修改後只逆轉已核准的相機句，用相同輸入及 seed 比較其他 bytes；新增斷言獨立核對新句本身，不能僅靠正規化讓測試通過。既有歷史 snapshots 不重寫。

必跑聚焦、Prompt Quality、完整前端測試、lint/build、同 seed strict audit；瀏覽器核對六組全身、切回中景、GPT/MJ 與五工作區桌面／手機 smoke。程式通過與使用者影像驗收分開記錄。

## 本輪驗證紀錄

- 431 組凍結案例：55 組姿勢／角度、110 組排除路徑、24 組方位、12 組光學、230 組既有上方場景案例。所有非核准差異的輸出、selection 及 RNG hash 一致。
- 五個新增聚焦測試含 Saved Cards／Markdown 文字及 angle/framing 保留；完整前端 913/913、Prompt Quality 245/245、lint、build 通過。Build 仍有既有大型 chunk 提醒。
- 相同 count 200／seed `prompt-quality-baseline` 的 strict audit 前後皆零 blocking、23 diagnostic-only（19 服裝／場景、4 near-duplicate）；未因稽核擴大修改其他邏輯。
- 桌面 1440×1000、手機 390×900 檢查五工作區。PAGE1 全身各角度與荷蘭角即時文字正確；切回中景恢復舊句；DLL 來源切換後恢復 Gpt。六張既有 Saved Cards 保留，未新增或刪除。
- 手機 PAGE1 既有工具列擁擠與窄三欄輸出仍存在，本輪不改 CSS/JSX。複製／下載的瀏覽器端交付 bytes 尚未重新驗證，不能將 codec 測試等同完整端到端驗收，因此 Browser 為 PARTIAL。
- 本輪瀏覽器 warning/error logs 為空，檢查畫面未見破圖。已恢復原本牛仔中景／腰部高度／左側、DLL Gpt、A 頁籤與瀏覽器 viewport；沒有改動其他工作區選項。
- 本輪沒有呼叫外部影像生成。六組 [正式組裝器測試 Prompt](z-image-full-body-camera-v1-test-prompts.md) 提供後續實測，不代表所有模型已通過影像驗收。
