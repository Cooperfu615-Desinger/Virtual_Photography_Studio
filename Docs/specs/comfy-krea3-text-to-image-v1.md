# DLL：Krea 3 文字生圖

## 範圍

- 使用提供的 Comfy Cloud API 工作流 `Krea3ImageNode`，只支援文字生圖；不提供參考圖、精準編輯或需要參考圖的 Ultra。
- 預設 1K、Fast、1 張；可選 1K／2K、Fast／High、1／2 張。每張完成且取得圖片後才送下一張，沿用既有任務追蹤與中斷不重送保護。
- 比例可選自動、1:1、4:5、3:4、2:3、9:16、5:4、4:3、3:2、16:9、21:9；固定比例的 Prompt 來源繼續鎖定其比例。Krea 3 會改寫 Prompt，因此相同 Seed 不保證相同圖片。
- 工作流固定使用 Krea 3、`precise_edit=false`、已匯出的 `SaveImageAdvanced` 節點 7。前端不提供任意工作流或節點名稱；無效比例、解析度與模式在提交扣額前拒絕。指定兩張 Seed 時，先檢查第二張的 Seed 範圍。
- 生成模式記錄在任務快照與實際設定，沿用設定時恢復。合作夥伴計價僅顯示 Cloud 餘額，現有估算機制不猜測單張費用。

## 驗證邊界

使用者已在 Comfy Cloud 以提供的 JSON 成功生成；DLL 的模擬驗收不代表已實際呼叫 Cloud、取得圖片、扣額或完成下載驗收。新功能的 commit／push、Functions 部署及付費實測需另外授權。
