## 建議套用原則

1. 僅腰部／膝蓋／地面／蟲眼機位考慮上方候選；其餘角度維持第一版。
2. 每次最多一至兩個短片語，已存在就不重複。清單列出兩項代表候選上限，不代表每次必須全放。
3. 優先使用同場景已存在的來源。新增候選另經確認，才成為按場景 ID 指派的結構化來源；不能由 renderer 自行猜測新物件。
4. 「既有來源」不保證目前每個景別都輸出，也不是全部無條件補回。未來需逐一審查既有壓縮／裁切與候選選用的關係，不把被省略的完整長句全部還原。
5. 片語放進既有場景開頭；不寫「必須完整顯示」「從人物頭頂到屋頂都入鏡」等要求，也不改鏡頭高度、人物比例或姿勢。
6. 不增加時間、天氣、光束、照明色溫；既有燈具只當場景物件，不額外指定它如何照亮人物。天空維持環境光來源，不由場景補充重複新增。
7. 桅杆、尖塔、遠景高樓等保持原來距離與語意，不能全部加上 overhead。既有線束／書架新增位置或材質也列入「新增候選」，不冒充原文照搬。
8. 未列入候選的場景及未知／自訂來源保守維持第一版；不新造遮雨棚、樹冠、上層窗戶作通用 fallback。
