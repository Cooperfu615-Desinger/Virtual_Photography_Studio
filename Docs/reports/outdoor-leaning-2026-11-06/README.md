## 產品結果

D 區沿用「靠在哪裡」，既有背部倚靠／側肩倚靠可在 71 個戶外選單場景使用。每個場景依姿勢提供基本名詞；新增樹幹、岩壁、販賣機、車廂，沿用牆面、柱子、門框、欄杆、直桿。背部有八個、側肩有十一個空清單，其中七場景兩者皆空，只提供未指定，不補物件。未指定沿用身體方向句；選物件後用接觸句取代，不累加兩句。

產品程式只改 `indoorLeaning.js`，接入獨立的戶外清單與四個名詞，其餘沿原生成／投影／切換／還原流程。沒有變更 UI／CSS、renderer、正式 catalog／registry、場景英文、室內清單或坐姿模型。可選欄位仍為 `indoorLeanId`，不新增 storage key、必填預設或資料遷移。

Grok Imagine 保留完整姿勢與接觸，其餘六組仍依原投影；欄杆只支撐下背，中景／胸上／頭部主導近景保留原方向句，全身角色照維持自然站姿。有效值跨場景、動作及室內外保留，失效回未指定並沿用提示。兩個動作仍 pending、手動可選，沒有加入隨機池。
