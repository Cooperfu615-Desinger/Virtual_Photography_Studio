## 16 段差異的保留依據

本批不以「較詳細」判定哪一用途正確，也不把兩份文字互相補齊。下表分類用來固定目前責任；完整兩側原文已記錄在審閱 JSON。

| 角色／圖層 | 差異 | 本批處理 |
| --- | --- | --- |
| Sakura／top、Yuri／top | 圖層以連接詞組合內外衣，profile 用不同串接 | 保留兩種句法 |
| Yuna／shoes、Nana／shoes、Miku／shoes | 鞋襪用 and 或逗號串接 | 保留原組合順序及標點 |
| Kaori／neckAccessory | 頸飾項目串接方式不同 | 保留原串接 |
| Miku／neckAccessory | striped navy／navy striped 語序不同 | 不改寫色彩或形容詞順序 |
| Yui／shoes、Grace／shoes | default footwear／locked footwear 用途措辭不同 | 保留原狀態語意，不借用 Hina 同字串當來源 |
| Rei／outerwear | 圖層有 relaxed sleeves 細節 | 保留，不增補 profile |
| Amy／top | 圖層有口袋與抽繩細節 | 保留，不裁定視覺真偽 |
| Amy／shoes | 圖層有黑色鞋底細節 | 保留，不增補 profile |
| Minji／top | 圖層有細肩帶細節 | 保留，不增補 profile |
| Manami／outerwear | 圖層明示外套敞開 | 保留，不變更遮蔽政策 |
| Kaori／outerwear | 圖層有銀色五金細節 | 保留，不增補 profile |
| Kaori／ring | 圖層有 stacked 戒指細節 | 保留，不增補 profile |
