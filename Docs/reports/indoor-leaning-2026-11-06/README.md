## 交付與限制

實作與驗證以最新 main 的隔離副本進行，通過後以限定清單提交、快轉接回 main 並推送；共享主工作目錄的四個 Saved Cards 修改與其他未追蹤檔保留。未修改原目錄 JSON、場景英文、registry、舊動作或既有歷史封存。未進行 Firebase 部署、真人資料操作或付費生圖。

兩個新動作維持 pending（介面顯示未驗收），可手動選擇，不進隨機池。這次證明程式輸出與選項相容，不宣稱 Grok Speed／Quality 或其他模型已能穩定生成接觸姿勢。戶外、固定構圖、匯入場景、雙人、角色卡／特殊主體、觀察式抓拍仍由原模式接管，不提供這套倚靠物件。CI／Pages 交付結果以實際提交的遠端作業為準，與本機紀錄分開。
