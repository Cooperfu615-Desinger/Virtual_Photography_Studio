## 產品結果

唯一產品程式修改為 `indoorSeating.js`：擴充原共用模型與物件詞表，讓所有輸出、UI 與還原沿原流程取用同次有效來源。沒有重寫 renderer、UI、收藏格式、正式 catalog、registry、場景原文或倚靠規則；欄位仍為可選的 `indoorSeatId`。

Grok Imagine 保留完整姿勢；其他六輸出仍依原姿勢投影，全身角色照維持自己的自然站姿。四個原本直接坐地的動作，在明確選定的純草地／沙地／三個平台場景一致替換各處接觸詞，保留手腳及承重。混合草地／道路、岩岸等保留通用地面；不把固定坐地動作搬到石頭、椅子或矮牆。

## 邊界與交付

實作與驗收使用最新 main 的隔離副本，通過後限定提交、接回 main 並推送。原四個 Saved Cards 已修改檔與未追蹤檔保持，不納入本次提交。未修改私人收藏、提交付費工作或部署 Firebase。

一般單人、手動場景與指定坐姿適用；固定構圖、雙人、匯入場景、角色卡／特殊主體、觀察式抓拍及舊動作卡仍由各自來源接管。尚未進行 Grok Speed／Quality 等外部模型生圖驗收。CI／Pages 的實際提交結果於交付後另行核對，不由本機測試推定。
