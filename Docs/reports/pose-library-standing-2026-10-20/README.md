# 站姿第一批：出圖驗收

- 日期：2026-10-20
- 目的：驗證 [站姿草案](../../specs/pose-library-standing-v1.md) 的 9 個動作與 4 句通用手勢，在四個模型上能不能畫對。通過的動作標記為 `accepted`，才會進入「隨機」池。
- 測試 Prompt：[prompts.md](prompts.md)，由 `tools/build_pack.mjs` 產生（在 `webapp/` 執行，見檔頭註解）。姿勢句放在引擎輸出「任意」的位置，手勢用引擎實際的插入方式，所以和實作後的輸出位置一致。

## 組別（13 組 × 4 模型）

| 組 | 內容 |
| --- | --- |
| 3.1–3.9 | 9 個站姿動作，不搭手勢 |
| 3.1+手勢 | 自然站姿＋雙手插前口袋 |
| 3.2+手勢 | 單腳重心＋撥頭髮到耳後 |
| 3.3+手勢 | 交叉腿站姿＋雙手輕握於髖前 |
| 3.4+手勢 | 側身窄站姿＋一手放鎖骨 |

建議張數：Z-Image 每組 4 張（seed 1–4）、MJ 每組一次四宮格、GPT 與 Nano 每組 2 張。額度有限時，先跑 Z-Image 全部 13 組，GPT 只跑 3.3、3.7、3.8、3.9 與 4 組手勢（姿勢差異最大、最容易畫錯）。

## 第二批（15 組 × 4 模型）

- 測試 Prompt：[prompts-batch2.md](prompts-batch2.md)，由 `tools/build_pack_batch2.mjs` 產生；每組附參考圖檔名（`Docs/站姿/`）。
- 6.1–6.11：參考圖動作，手部照參考圖固定；評分時「身體幾何」包含手部。
- 4 組新手勢：自然站姿＋雙手背後、單腳重心＋一手扶頭、併腿微屈站姿＋雙手抱頭後、側身窄站姿＋雙臂上舉。
- 額度有限時，Z-Image 先跑全部 15 組；GPT 先跑 6.5、6.6、6.10（單腳抬腿）、6.8、6.11（舉臂）與 4 組新手勢。

## 檔名

放進 `Docs/參考/`，建議：`{模型}_{組}_{編號}`，例如 `Z_3.7_01.png`、`GPT_3.1+手勢_02.png`。

## 評分（每張）

| 項目 | 分數 |
| --- | --- |
| 站姿正確（不是坐、跪、走路） | 是／否 |
| 身體幾何符合（core＋lower 各子句） | 0 不符、1 部分、2 符合；註明哪一句沒做到 |
| 手勢符合（手勢組才評） | 0 不符、1 部分、2 符合 |
| 自然度 | 0 僵硬或怪異、1 可接受、2 自然 |
| 畸形（手、腳、肢體數量或連接） | 有／無 |
| 其他 | 是否全身、人數 |

## 判讀規則

1. 一個動作在某模型「身體幾何」平均 ≥ 1.5 且畸形 ≤ 1 張，視為在該模型通過。
2. 四個模型中至少三個通過，動作標記 `accepted`；只能測部分模型時，由 Cooper 目視判斷（2026-10-19 起的驗收方式）。
3. 手勢在多數模型「手勢符合」< 1 的，改寫英文後重測。
4. 3.8 若沒有明顯前傾探身，改寫英文後重測。
