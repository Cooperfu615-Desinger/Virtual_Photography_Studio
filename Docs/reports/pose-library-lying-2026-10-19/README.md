# 躺姿第一批：出圖驗收

- 日期：2026-10-19
- 目的：驗證 [躺姿草案](../../specs/pose-library-lying-v1.md) 的 3 個動作與 4 個躺姿機位，在四個模型上能不能畫對。通過的動作標記為 `accepted`，才會進入「隨機」池。
- 測試 Prompt：[prompts.md](prompts.md)，由 `tools/build_pack.mjs` 產生（在 `webapp/` 執行，見檔頭註解）。

## 條件（6 組 × 4 模型）

| 組 | 動作 | 機位 |
| --- | --- | --- |
| 4.1-平視 | 側躺・臉靠枕頭・上手輕握枕邊 | 貼地／床面平視 |
| 4.1-俯拍 | 同上 | 正上方俯拍 |
| 4.2-斜俯 | 趴躺・前臂撐起・雙腳交叉翹起 | 斜上方俯拍 |
| 4.2-頭頂 | 同上 | 從頭頂方向拍 |
| 4.3-平視 | 趴躺・前臂撐起・單腿屈起 | 貼地／床面平視 |
| 4.3-俯拍 | 同上 | 正上方俯拍 |

建議張數：Z-Image 每組 4 張（seed 1–4）、MJ 每組一次四宮格、GPT 與 Nano 每組 2 張。額度有限時，先跑 Z-Image 與 GPT。

## 檔名

放進 `Docs/參考/`，建議：`{模型}_{組}_{編號}`，例如 `Z_4.2-頭頂_01.png`、`GPT_4.1-平視_02.png`。

## 評分（每張）

| 項目 | 分數 |
| --- | --- |
| 方向正確（側躺／趴躺） | 是／否 |
| 身體幾何符合（核心＋上身＋下身各子句） | 0 不符、1 部分、2 符合；註明哪一句沒做到 |
| 機位符合 | 0 不符、1 部分、2 符合 |
| 自然度 | 0 僵硬或怪異、1 可接受、2 自然 |
| 畸形（手、腳、肢體數量或連接） | 有／無 |
| 其他 | 是否全身、是否在床上、人數 |

## 判讀規則

1. 一個動作在某模型「身體幾何」平均 ≥ 1.5 且畸形 ≤ 1 張，視為在該模型通過。
2. 四個模型中至少三個通過，動作標記 `accepted`。
3. 機位在多數模型「機位符合」< 1 的，改寫英文後重測，或從清單移除。
4. 「從頭頂方向」的趴躺結果，也用來判斷 §2 相容表中 △ 組合是否限制。
