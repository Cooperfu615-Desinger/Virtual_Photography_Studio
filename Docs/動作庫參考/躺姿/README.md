# 躺姿參考圖

神情姿態 v2 動作庫用的躺姿參考圖。規格：[expression-pose-v2.md](../../specs/expression-pose-v2.md)。

## 放圖方式

- 一個動作一張主圖；同一個動作有不同角度或細節的補充圖，可以加在同一個編號後面。
- 檔名建議：`{方向}_{編號}.{副檔名}`，例如 `仰躺_01.jpg`、`側躺_03.png`、`趴躺_02.jpg`、`半躺_01.jpg`。補充圖用 `仰躺_01b.jpg`。
- 方向不確定時，直接用 `躺姿_01.jpg`，討論時再分類。
- 想特別強調的地方（例如「只要腿的姿勢」「手上的道具不要」），可以寫在下方的備註表。
