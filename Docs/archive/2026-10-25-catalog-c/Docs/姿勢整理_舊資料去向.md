## 判讀方式與相容邊界

1. **資料標記不是歷史介面證據。**「未全域隱藏」只表示未設 `meta.uiHidden`；「全域隱藏／退役」表示 `uiHidden: true`、`deprecated: true`。可見性另受 `base`／`bases`、`hiddenForBases`、`hiddenForOrientations` 及相容條件影響。本文沒有逐版重建舊 UI，不能據此宣稱每筆「曾公開」。
2. **目前舊自由組合入口已退役。** P4／P5a 的工作台流程會清除 `poseBaseId`、`poseOrientationId`、`poseArrangementId`、`poseHandId`、`posePropId`、`poseHeadId`、`poseAnchorId` 的退役值；自拍資訊另轉成拍攝方式。引擎仍保留舊資料與讀取路徑，不能把「引擎可處理」當成「現行 UI 可選」。此處指載入／回填後的工作台狀態，不代表批次改寫或刪除已保存的原始收藏。[E7]
3. **文字改編不等於自動遷移。** 表內新舊 ID 只記錄開發來源；沒有宣稱舊 ID 會被程式自動換成新 ID。「概念相近」是功能覆蓋比較，不是等價輸出、alias 或正式映射。沒有列出改編來源，也不代表所有相似概念均不存在。
4. **accepted、隨機資格與出圖驗收分開。** `accepted` 是程式狀態；部分動作依既有文字授權納入，出圖統一實測仍延後。下表「一般池」指 `SPECIFIED_ACTION_RANDOM_POOL` 成員，實際抽選仍受單人、固定場景與相機衝突等條件限制；躺姿另需鎖定的場景有可用表面，枕頭動作要求床。不能只讀 `meta.randomEligible` 判定指定動作隨機資格。[E2]、[E8]
5. **保留不等於可立即重開或可刪除。** 恢復公開需另行確認需求，處理入口、支撐／手勢、裁切、匯入回填及 Prompt 驗證。P5b 仍延後，目錄資料架構仍停在已驗收 A；本文不是 B 的 ID 登記簿，也不授權開始 B、P5b、改寫基準或刪除資料。[E9]、[E10]
6. 舊「任意」與現行指定動作 `any` 是不同輸入與文字契約，不能當成逐字替換或自動遷移；現行躺姿的方向由各動作 `orientationId` 決定。
